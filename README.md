# 사택 공용공간 당번 관리

윤다니엘 → 박창수 → 김경민 순으로 매주(월요일 교대) 화장실 청소 / 분리수거 당번을 관리하는 정적 웹사이트입니다.

- 기준일: **2026-09-14(월) = 박창수**
- 순번은 매주 자동으로 계산되며, 기준일 이후/이전 어떤 주에 대해서도 당번을 알 수 있습니다.
- 캘린더에서 원하는 주를 클릭하면 해당 주의 당번과 체크리스트(화장실 청소, 분리수거)를 확인/체크할 수 있습니다.
- 체크 상태는 브라우저의 `localStorage`에 저장됩니다(기기/브라우저별로 별도 저장).

## 실행 방법

별도 빌드 없이 정적 파일만으로 동작합니다. 아래처럼 로컬 서버로 열어보세요.

```bash
python3 -m http.server 8080
# 이후 브라우저에서 http://localhost:8080 접속
```

또는 GitHub Pages 등 정적 호스팅에 `index.html`, `styles.css`, `script.js`를 그대로 배포하면 됩니다.
